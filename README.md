# Information Retrieval

Song Search Engine App. The [InformationRetrievalReport.pdf](https://github.com/georgekarathanos/search-engine/blob/master/InformationRetrievalReport.pdf) is a short explanation of the system (in Greek) and includes screenshots of the web application.

#### About this app

1) This is a web application that is a search engine for songs. It is very easy to use as its UI is very similar to Google's. It supports incognito search, voice recognition, and boolean queries. Furthermore, it supports semantic retrieval and in each case presents the top songs to the user. The user can click on one of the retrieved songs and read its lyrics.<br /><br />
2) The songs were downloaded from Kaggle and indexed using the Lucene library. The retrieval of the songs is also supported by Lucene's APIs. In general, the web application is built with Java, HTML, JavaScript and Spring Boot. For the semantic retrieval (using machine learning) the ND4J library was used.<br /><br />
3) In order to run this web application:<br />  i) Download the source code from this repository.<br />   ii) Open Eclipse or IntelliJ (IntelliJ is preferred because in Eclipse you will probably need extra configuration).<br />  iii) Import the 'inforet' folder as a Maven project.<br />  iv) Run the SQL script you will find under the recourses/DDL folder in order to create the necessary table in your database.<br />   v) Change the username/password in the properties file to your MySQL account information.<br /> vi) Download glove.6B.zip from https://nlp.stanford.edu/projects/glove/ and put the glove.6B.50d pretrained model under the recourses/DDL folder.<br />  vii) Execute the filter.py program under the recourses/DDL folder and now you have your word2vec model ready.<br /> viii) You are good to go! Fill the comments of the code with your paths, execute the program and go to localhost to navigate the application.
